A program that draws a 1024x1024 newspaper front page summing up 24 November 2026 world news in six panels: the deadly Russian strike on an apartment block in Zaporizhzhia, the killing of Hamas security chief Naeem Abu Nahel in Gaza City, Russian jets entering South Korea's air defence zone, Oregon and Virginia suing SpaceX over Grok-generated sexual images, 25 hostages taken at a supermarket in Cartagena, and fighting in Ituri trapping Ebola responders. Each panel pairs a simple flat illustration with a bold headline and a one-line caption carrying the key fact, under a masthead and the date "Tuesday 24 November 2026".

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
